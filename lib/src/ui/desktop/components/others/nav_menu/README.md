# 导航菜单

`ElNavMenu` 使用 40 高菜单行、8 圆角、20 图标和浅色强调填充；紧凑模式缩小文字与图标。明暗配色读取共享主题 token，用户 style 最后合并。

`ElMenuModel(group: true, title: '开始使用', children: [...])` 仅声明视觉分组，可省略 key。分组展示弱化标题和留白，无箭头、点击、选中或折叠状态；子项按当前深度直接展开，不增加缩进。导航分组不添加分割线。

普通带 children 的节点仍是可折叠子菜单。默认选中首个真实叶子，路由高亮路径忽略分组，`toFullPath` 穿透分组且保留图标、data 和 group 标识。普通构造继续使用公共值绑定，router 构造监听路由代理。

右键菜单另行处理：用户要求其分组使用“分割线＋分组标题”，这是后续优化项，不复用导航分组的留白规则。
