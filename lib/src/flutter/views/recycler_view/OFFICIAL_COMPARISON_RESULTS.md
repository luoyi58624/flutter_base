# RecyclerView 与官方 ListView：同条件无头对照

2026-11-06；Flutter 3.47.5 / Dart 3.13.4；数据见 [OFFICIAL_COMPARISON_RESULTS.json](OFFICIAL_COMPARISON_RESULTS.json)。

三轮正式对照中，六个场景的池化平均耗时均低于官方 ListView，降幅为 **12.25%–67.93%**。
这表示同一批次、同一夹具下完整 `jumpTo + pump` 的主机墙钟差异，不能换算成手机 Profile 帧耗时、FPS 或触摸延迟。
卡片小幅滚动第 3 轮均值较官方高 **4.93%**，部分轮次 p95 也较差；不能据此声称所有场景稳定领先或完全消除掉帧。

## 正式结果

单位为 ms；每个单元包含三轮全部 **144 帧**。R/L 为 RecyclerView 均值除以 ListView 均值，越低越好。
“降幅”仅指当前两种容器之间的均值差异，不是这次代码修改前后的因果提升。

| 文本 · 3px | 8.615 | 6.841 | 14.246 | 11.066 | 0.7940 | 20.60% | 0.6723–0.9137 |
| 文本 · 一行 | 6.881 | 6.025 | 10.296 | 10.259 | 0.8756 | 12.44% | 0.7531–0.9646 |
| 文本 · 900px | 36.759 | 22.030 | 71.432 | 40.535 | 0.5993 | 40.07% | 0.4991–0.7676 |

文本按行池化 p95 为 10.296→10.259ms，差异很小，不应把这个尾部结果描述成明显胜出。

## 夹具与统计边界

- 真实 10,000 条 `RecyclerTextPage` 文本；官方直接构建相同 `ElView`，没有人为套入 RV 的 Hook/Notifier。
- 真实 10,000 张 `RecyclerCardsPage` 卡片；保留官方原有 **itemExtent=540**，RV 没有额外固定行高捷径。
- 390×600 视口、DPR=1、文字缩放=1、测试字体 Ahem；主题、padding=0、Clamping 物理一致。
- 官方缓存范围为 0；RV cache=0、预取关闭；关闭 keepAlive，各项只有一个容器提供的重绘边界。
- 语义开启，阴影开启；两张实际离线照片预解码。原页面仅在 Offstage 维持真实模型的生命周期。
- 两边具有同一个轻量 RenderProxyBox，只计创建/释放、performLayout、paint；主批次不安装全局构建追踪、不添加逐项 Stopwatch 或 Timeline 采样。
- 轨迹为每帧 3px、约一条目的实测高度、900px；每段先向前再向后，实际偏移、可见位置、正文、图片、图标与几何逐帧核对。
- 第 1/3 轮顺序 **L-R-R-L**，第 2 轮 **R-L-L-R**；L 为官方，R 为 RV，反序用于减轻固定先后顺序的影响。
- 每段预热 8 帧，正式记录 24 帧（前进/后退各 12）；每轮每模式 48 帧，三轮每模式 144 帧，共 **18 records / 1728 frames**。
- 三轮正式样本全部保留，不挑最好轮次、不去极值；mean 对原始微秒求均值，p50/p95 使用 nearest rank，池化分位数直接计算 144 帧。
- finder、树扫描、内容断言均在计时区间外；空闲 pump 单列而不从正式耗时中相减。计时外的检测分配仍可能影响后续 GC。

## 单独的阶段诊断

`profile-cards-small.log` 仅一场景，开启测试进程自己的 VM Timeline；**不混入正式 144 帧池**。
该批官方/RV 的窗口均值约 **1.925/1.867ms**，明显低于正式池化的 4.208/3.692ms，说明绝对墙钟耗时存在很大批次波动。
这与 JIT 预热、系统调度和共享主机状态有关的解释相容；本次没有 CPU 负载采样，不能把差异归因于其中单一因素。

| 阶段均值 | 官方 | RV |
| --- | ---: | ---: |
| LAYOUT | 0.229ms（两段约 0.202–0.256） | 0.119ms |
| PAINT | 0.091ms | 0.080ms |
| SEMANTICS | 1.046ms（两段约 0.832–1.261） | 1.074ms |

此场景没有条目创建、绑定或外层 row performLayout/paint；语义仍占完整帧的大头，仅看很低的布局耗时无法解释整个 pump。
阶段按每帧时间窗裁剪并取区间并集；互斥分区把嵌套 BUILD 从 LAYOUT 中分出，不把包含关系的 inclusive 耗时直接相加。
GC 任意线程重叠量为官方 **1406µs**、RV **1707µs**（各 48 帧合计）；这不是 UI 线程暂停时长，也不能单独证明掉帧原因。

## 已消除的确定性工作

以下结论来自代码路径和回归断言；正式表格没有给这些单项改动分别分配“提升百分比”。

1. `viewport.dart` 在真实挂载/移除时缓存 RenderBox，避免每项约 5–6 次沿约 8 层包装链读取 `Element.renderObject`。
2. 退场通常按 holder 位置直接删除，避免每个退场项扫描整个活动表；稳定 ID 重映射仍保留按旧键查找的 fallback。
3. 同窗口平移不遍历更新条目偏移；paint、hitTest、applyPaintTransform 共用已提交的像素/方向快照，单次坐标计算为 O(1)，整段可见项遍历仍为 O(V)。
4. 视口自身加入绘制隔离。无滚动条/边缘装饰的测试中，滚动 1px 或 250px，未变化祖先 paint 从 **1→0**；新记录仍能重新绘制与命中。
5. 移除 performLayout 内重复的手动语义标脏，沿用 SDK 布局后的语义失效；语义管线仍开启且仍有成本。
6. 没有 OnScrollListener 时提前返回，减少方向解析和监听器快照数组；真实监听器路径保留原通知语义。
7. 文本无 WidgetSpan 时复用空集合，无选区时不创建 Path；连续非空 String 换字复用已解析样式与配置键，新字仍重新排版，样式/环境变化仍使缓存失效。

窗口快路同时保留布局代次保护、预取期间 computingLayout 防护及最新 ScrollPosition 维度快照，避免用旧几何掩盖真实失效。
卡片按行/快滚正式池分别出现官方创建 **144/240** 条、RV 创建 **0/0** 条并换绑 **144/240** 次，支持真实结构复用。
外层 row performLayout 为 0 不代表动态文本叶子没有排版；复用 Element/RenderObject 不能消除新文字的 TextPainter.layout。

在 `example/` 下运行下列单批命令；正式采样不启用 PROFILE/DETAIL，反序批次添加 `--dart-define=RECYCLER_COMPARE_ORDER=RLLR`。

```powershell
flutter test test/recycler_official_comparison_test.dart --no-pub --concurrency=1
flutter test test/recycler_official_comparison_test.dart --no-pub --concurrency=1 --enable-vmservice --plain-name "cards/small" --dart-define=RECYCLER_COMPARE_PROFILE=true
```

当前没有新增真机、触摸物理、输入采样或 Android 原生调度对照数据；这些无头结果不足以承诺手机上恒定 1ms 或与原生完全一致。
