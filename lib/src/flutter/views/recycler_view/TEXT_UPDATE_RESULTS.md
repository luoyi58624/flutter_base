# RecyclerView 文本换绑与滚动优化复测

2026-11-06。完整数据与统计：[TEXT_UPDATE_RESULTS.json](TEXT_UPDATE_RESULTS.json)，保留原三轮 **36 条记录**及独立诊断 **8 条记录**。

## 结果

真实文本行已保留 Element、RenderObject、TextEngine、TextPainter，更新没有整行销毁重建。同一 current 进程的短文本对照中，保留 TextPainter 换文的 p50 是新建排版的 **1.28–1.32 倍**，不能声称保留换字本身更快。

关闭预取、绑定工作相同的快跨屏，三轮 p50 配对比值中位数为 **0.929，约改善 7%**；p95 和小幅滚动 p50 **没有稳定改善**。减少了冗余工作已由计数证明，但不能据此宣称整体滚动显著提速，或换算成安卓真机帧率。

基线隔离副本仅移植相同测试和等价 assert 探针，未移植生产优化。入口：[recycler_text_cost_test.dart](../../../../../example/test/recycler_text_cost_test.dart)。取真实示例 Adapter 放进无 AppBar、无滚动条的新窗口。表格单位 **ms**，JSON 原始样本为 **µs**；每轮 p50/p95 取排序后第 12/23 个样本。三轮中位数、范围和逐轮 current/基线比值均在 JSON；“比值中位数”不同于“两个耗时中位数之比”。

创建/更新/滚动并 pump 是主机完整 pipeline 墙钟，不能减去空 pump 声称净成本。`pump(Duration(milliseconds: 8))` 推进虚拟时钟，不代表设备帧耗时。独立 TextPainter 对照不含 Widget/Element/RenderObject 与 pump；新建的 dispose 在计时外。

## 生产改动与边界

- [text_engine.dart](../view/text/text_engine.dart)：非空 String 换字跳过选择归属祖先重扫，保留几何和内容通知；首次、空内容及类型资格转换仍同步。
- 主 painter 独立配置键避免布局后 paint 重复 configure；不依赖提前被 reposition 改写的 `_input`。颜色、字号、缩放、方向、locale、粗体仍正确失效，dry/选择覆盖层不污染主缓存；String/无占位内容走快路。文本两文件合计仍不超过 800 行。
- [viewport.dart](viewport.dart)：可见窗口边界不变、邻项不需进入且无待处理变更时仅移动现有子项；完整填充沿实测高度累计，未改高不逐项重求锚点。
- 约束、失效代数、最新 scroll metrics 和 computing guard 防止数据/子树/环境变化或布局回调失效被平移快路吞掉。本次未混入手势接管或滚动物理改动。

## 真实行创建与保留更新

捕获的实际行：**2 Element / 0 State / 1 RenderObject / 1 TextEngine / 1 TextPainter / 0 RenderParagraph**。测试跨 999→1000 换绑 24 个不同位置，逐次断言对象身份与最终文本；更新的 Element/RenderObject 增删、Engine/Painter 新增均为 0。创建对照要求与前次对象集合不交叉，卸载后对象确实释放。

| current 轮次 | 创建、绑定、挂载、pump p50 / p95 | 保留换绑、pump p50 / p95 | 更新/创建 p50 |
|---|---:|---:|---:|
| 1 | 2.350 / 3.520 | 1.977 / 2.602 | 0.841 |
| 2 | 2.813 / 3.643 | 2.241 / 3.053 | 0.797 |
| 3 | 2.206 / 3.433 | 1.730 / 2.180 | 0.784 |

更新/创建 p50 配对比值中位数 0.797，本例省约 20%，不是仅剩 1/3。基线→当前的三轮耗时中位数：创建 p50 3.086→2.350、p95 4.177→3.520；更新 p50 2.490→1.977、p95 3.162→2.602。回调、卸载、空 pump 和每个样本均完整保存在 JSON。

快跨屏 cache0 两版本每轮均为 816 次跨记录换绑、零新 holder、零已有行 Element 增删及 Painter 销毁；同时仍有 816 次行 build 和 layout，因为内容确实改变。**保留结构不等于不执行 build，也不等于新文字无需排版。**

## 同一进程的纯 TextPainter 对照

使用真实行已解析配置，字号 15、宽度 390；新建与保留换文交替先后，同样预热 4 次、测量 24 次。

| current 轮次 | 新建排版 p50 / p95 | 保留换文排版 p50 / p95 | 换文/新建 p50 |
|---|---:|---:|---:|
| 1 | 0.030 / 0.035 | 0.039 / 0.045 | 1.300 |
| 2 | 0.031 / 0.070 | 0.041 / 0.047 | 1.323 |
| 3 | 0.039 / 0.055 | 0.050 / 0.083 | 1.282 |

新建 p50 为 30–39 µs，保留换文为 39–50 µs，没有测到更快。内容变化仍需新文字 shaping/layout；对象身份保留不能推出底层排版免费。跨进程的基线/current 波动也不能充当“换文更快”的证据；此短文本结果不外推至长富文本、设备字体或 Profile AOT。

## 三轮滚动完整 pipeline

三轮数组按第 1/2/3 轮排列；最后一列是**逐轮 current/基线比值中位数〔最小–最大〕**，小于 1 表示降低。

| 场景 / 分位数 | 基线三轮 ms | 当前三轮 ms | 配对比值 |
|---|---:|---:|---:|
| 快跨屏 cache0 / p50 | 21.948 / 17.617 / 17.459 | 17.836 / 16.372 / 16.374 | 0.929〔0.813–0.938〕 |

| 小幅 3px cache0 / p50 | 3.295 / 3.196 / 3.174 | 2.695 / 3.383 / 3.429 | 1.059〔0.818–1.080〕 |

相同工作量的 cache0 快跨屏 p50 三轮均下降，中位耗时 17.617→16.374 ms；p95 第二、三轮上升，中位 19.777→20.927 ms。小幅 cache0 p50 第二、三轮也上升，中位 3.196→3.383 ms。不能挑首轮基线普遍较慢的结果作为稳定收益。

默认预取有工作量干扰：快跨屏 cache2 基线绑定 `[817,817,817]`、新 holder `[1,1,1]`，当前绑定 `[816,816,817]`、新 holder `[0,0,1]`；第三轮总数相同，发生帧仍不同。小幅 cache2 基线绑定 `[0,4,1]`、当前 `[0,0,2]`，跨记录更新分别 `[0,2,0]` 与 `[0,0,0]`。这些不是完全相同绑定工作的对照；cache0 两版本逐帧绑定工作相同。生产墙钟预取预算及测试虚拟时钟的保守回退造成波动，未为数字好看改预算。

## 一次独立同步布局诊断

原三轮之后，两版本各测一次四场景，共 **8 条**。两边同一 `_layoutContents` 入口/收尾增加相同 assert 内 Stopwatch，计同步准备、build/layout、scrap；不含后续独立 paint、pump 调度或设备 GPU。**它是另一数据集，不补成第 4 轮，不与前 36 条混算。**计时探针本身改变测量条件，assert 在 Profile/Release 不执行。

| 场景 | 同步布局基线 p50 / p95 | 同步布局当前 p50 / p95 | 整次 pump 基线 p50 / p95 | 整次 pump 当前 p50 / p95 |
|---|---:|---:|---:|---:|
| 快跨屏 cache0 | 20.130 / 41.249 | 20.915 / 26.837 | 28.525 / 49.517 | 28.417 / 34.715 |
| 快跨屏 cache2 | 18.777 / 25.027 | 16.033 / 20.820 | 25.089 / 32.670 | 22.405 / 27.503 |
| 小幅 3px cache0 | 0.648 / 3.070 | 0.357 / 2.650 | 6.118 / 9.913 | 5.328 / 7.458 |
| 小幅 3px cache2 | 0.659 / 1.545 | 0.375 / 3.260 | 5.019 / 7.805 | 4.701 / 8.301 |

cache0 小幅同步布局 p50 0.648→0.357 ms，但快跨屏 20.130→20.915 ms **并未更快**；一次诊断不能覆盖原三轮完整 pump 的结论。cache2 小幅 p95 上升且新 holder 基线 1、当前 2，仍有工作量差异。

确定性工作量门禁：6 帧稳定窗口旧版 full/item/prefix=`6/30/198`，当前 full/translate/item/prefix=`0/6/0/0`；均匀填充 prefix `29→3`。真实快跨屏 24 帧 prefix `4584→480`；小幅 cache0 full `24→12`、translate `0→12`、item `820→412`、prefix `5014→446`。这些证明少做了什么，不等于最终耗时按同比例下降。

## 验证和复现

**250 个不同测试通过**：核心 121、文本 73、选择 31、真实 row/card/chat 示例 19、真实文本成本/滚动 6。重复三轮、offset 子集 11 项、两次诊断各 4 项不重复累计。最终 8 个本轮 Dart 文件定向静态分析 **No errors**。

旧快路夹具直接修改已布局子 RenderObject 约束，破坏 semantics 一致性；现改为完整布局末尾由测试 host `markNeedsLayout` 触发真实失效，修正后核心 121 项通过。文本门禁还验证 24 次换字归属同步 `24→0`，并覆盖同宽通知、缩短选区、paint-only 颜色、配置次数、环境变化、dry/覆盖层隔离。

日志位于 `.codex-run/text-optimization-20261106/`：`core-verified.log`、`text-unit-first.log`、`selection.log`、`example-regressions.log`、`offset-final.log`、`paired-{1,2,3}-{baseline,current}.log`、`kernel-{baseline,current}.log`。JSON 含原始记录、逐轮统计、工作差异及日志 SHA256。

复现：在基线隔离副本和当前的 `example/` 分别执行 `flutter test test/recycler_text_cost_test.dart --no-pub --timeout=90s --concurrency=1 --reporter expanded --dart-define=RECYCLER_TEXT_LABEL=<版本与轮次>`，保留 JSON 并核对绑定数量。当前测试已有诊断探针，需注明与原三轮的区别。后续安卓结论应来自相同数据、相同绑定工作的真机 Profile/AOT 时间线；本报告没有测量触摸间隔、滚动物理和视觉稳定性。
